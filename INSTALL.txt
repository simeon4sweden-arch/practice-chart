PRACTICE CHART — iPad PWA (based on 5.12)

1. Create a public GitHub repository named practice-chart.
2. Unzip this package and upload its contents (not the enclosing folder) to the repository root.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open the published HTTPS address on iPad Safari. Share > Add to Home Screen. Enable Open as Web App if offered.
5. Launch from the icon while online. Open a PDF and export an annotated PDF to initialize the libraries. Wait for initial loading.
6. Turn on Airplane Mode, close and reopen the app, and test scores, annotations, export, practice chart and recordings before relying on it.

Offline dependencies are downloaded and cached on first online use, not bundled in this ZIP. Fonts may fall back to system fonts offline. IMSLP requires internet. iPadOS can clear local storage; keep independent copies of important PDFs and recordings. Existing local HTML data does not automatically transfer to this new website. No cross-device sync or complete backup/migration feature was added. Do not upload personal scores or recordings to GitHub.
